# Gestão Solidária — MVP (ONG Mesa Solidária)

Sistema web desenvolvido em Python (Flask) para apoio operacional aos voluntários da ONG Mesa Solidária.

## Funcionalidades do MVP
- Autenticação Segura (RNF01): Controlo de acesso para voluntários e coordenadores.
- Gestão de Lotes por PEPS (RF01): Registo e controlo de doações pelo critério Primeiro a Entrar, Primeiro a Sair conforme a validade.
- Validação de Entrega por CPF (RF03): Consulta prévia de beneficiários para bloqueio automático de entregas duplicadas no mesmo mês.
- Acessibilidade e Usabilidade (RNF04): Interface de alto contraste com alertas visuais claros para operação em dispositivos móveis.

## Tecnologias
- Back-end: Python 3, Flask
- Front-end: HTML5, CSS3
- Testes e Integração Contínua: Pytest, GitHub Actions
